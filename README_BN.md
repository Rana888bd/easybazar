# Easy Bazar — বিনামূল্যের ওয়েবসাইট

এটি HTML, CSS ও JavaScript দিয়ে তৈরি একটি responsive অনলাইন শপের নমুনা ওয়েবসাইট। GitHub Pages-এ ফ্রি প্রকাশ করা যাবে।

## ফাইল
- `index.html` — ওয়েবসাইটের কাঠামো
- `style.css` — ডিজাইন ও মোবাইল responsive layout
- `script.js` — পণ্য, সার্চ, ক্যাটাগরি, অর্ডারের তালিকা এবং WhatsApp checkout

## প্রকাশ করার নিয়ম (GitHub Pages)

1. https://github.com/ এ অ্যাকাউন্ট খুলুন বা লগইন করুন।
2. উপরের `+` → **New repository** নির্বাচন করুন।
3. Repository name দিন `easy-bazar`। **Public** নির্বাচন করুন, তারপর **Create repository** চাপুন।
4. **Add file** → **Upload files** চাপুন।
5. এই ZIP-এর ভেতরের `index.html`, `style.css`, `script.js` এবং `README_BN.md` ফাইলগুলো আপলোড করুন। ZIP ফাইলটি নিজে আপলোড করবেন না; ZIP extract করে ভেতরের ফাইল আপলোড করুন।
6. **Commit changes** চাপুন।
7. Repository-র **Settings** → **Pages** খুলুন।
8. **Build and deployment** অংশে **Deploy from a branch** নির্বাচন করুন।
9. Branch হিসেবে `main` এবং folder হিসেবে `/(root)` বেছে **Save** চাপুন।
10. এক-দুই মিনিট অপেক্ষা করুন। Pages অংশে দেখানো URL-এ ওয়েবসাইট খুলুন। সাধারণত URL হবে `https://YOUR-USERNAME.github.io/easy-bazar/`।

## WhatsApp নম্বর
`script.js`-এ `WHATSAPP_NUMBER = "8801516126330"` রাখা আছে। পরিবর্তন করতে হলে দেশের কোডসহ শুধু সংখ্যা লিখবেন; `+`, স্পেস বা ড্যাশ দেবেন না।

## পণ্য যোগ/পরিবর্তন
`script.js` খুলে `PRODUCTS` তালিকা সম্পাদনা করুন। প্রতিটি পণ্যে:
- `id`: আলাদা সংখ্যা
- `name`: পণ্যের নাম
- `category`: ক্যাটাগরি
- `price`: দাম (সংখ্যা, টাকা)
- `emoji`: পণ্যের অস্থায়ী ইমোজি ছবি
- `tag`: যেমন `নতুন` বা `জনপ্রিয়` (না চাইলে খালি string)
- `description`: সংক্ষিপ্ত বিবরণ

পরিবর্তিত `script.js` আবার GitHub repository-তে আপলোড/কমিট করলে সাইট আপডেট হবে।

## গুরুত্বপূর্ণ সীমাবদ্ধতা
- এটি একটি static website; আলাদা সার্ভার, ডাটাবেস বা admin panel নেই।
- অর্ডার WhatsApp-এ মেসেজ হিসেবে তৈরি হবে। অনলাইন পেমেন্ট, স্টক ম্যানেজমেন্ট, লগইন, অর্ডার ডাটাবেস বা স্বয়ংক্রিয় ডেলিভারি হিসাব নেই।
- নমুনা পণ্যের নাম/দাম/ইমোজি শুধু দেখানোর জন্য। প্রকাশের আগে নিজের আসল পণ্য, ছবি, দাম, ডেলিভারি/রিটার্ন নীতি এবং যোগাযোগের তথ্য বসান।
- যোগাযোগের WhatsApp নম্বরটি ব্যবহার করার আগে ঠিক আছে কি না পরীক্ষা করুন।
- Google Fonts ব্যবহৃত হয়েছে; ফন্ট লোড না হলেও সাইটের fallback font থাকবে।
- শুধু নিজের বা ব্যবহারের অনুমতি থাকা পণ্যের ছবি/বিষয়বস্তু ব্যবহার করুন।

## পণ্যের বাস্তব ছবি যোগ করতে
এখন কার্ডে ইমোজি আছে। বাস্তব ছবি ব্যবহারের জন্য প্রতিটি পণ্যের data-তে `image: "images/product-name.jpg"` যোগ করে `index.html`-এর product rendering-এ `<img>` ব্যবহার করতে হবে; চাইলে পরবর্তী ধাপে আমি এটি যুক্ত করে দিতে পারি।
